# moku Studio — 表現と編集の自由度を広げる設計

ユーザーの目的は、特定の参考画面に合わせることではなく、多様なUIを少ない操作で自分の意図どおりに表現すること。設計と細部の判断を任せ、そのまま実装する指示を受領済み。

## 方針

既存のReact/DOM描画を拡張する。描画基盤の全面置換も比較したが、文字編集・フォーム・HTML出力の連続性を優先する。部品数を増やすだけではなく、完成ブロックから始めて内部の要素まで編集可能にする。

## 成果

- 検索と試し書きを備えた実フォントの選択。日本語ゴシック・明朝と異なる欧文の字体を同梱し、ユーザーのフォントファイルも端末内に保存できる。
- 単色・線形/放射グラデーション、角別の丸み、枠線種、影の色/距離/ぼかし/広がり/内側、ぼかし、文字装飾、文字の垂直配置、内側余白。
- 編集可能な名前付き子レイヤーで構成する完成ブロック。追加後は通常のパーツと同じ操作で編集できる。既存の固定部品は明示操作でレイヤーへ展開できる。
- スタイルのコピー/貼付けと、選択範囲を自分の部品として保存・再利用する操作。テーマを選んだブロック挿入。
- コンテナを指定した追加、親の変更、配置の調整。テキストの内容に合わせた高さ調整。
- 旧JSONの読み込みを維持し、新しい装飾・フォント・保存部品をJSONへ保持。プレビュー、HTML、PNG/SVG、ZIP、仕様書を同じ設定に基づいて出力する。

## 使い心地

NomadKitの色はエディターの外観に使用し、制作物の色を強制しない。よく使う設定はすぐ操作でき、詳細は段階的に開く。見た目のプリセットを適用後も変更可能にする。自動保存、Undo/Redo、ロックを保持する。

## 判断と範囲

実フォントはライセンスを同梱し、アプリと同じ配信元から読み込む。フォント数だけを目標にせず、任意のフォントを持ち込める経路を設ける。オフラインで利用可能な字体と端末依存の字体を区別する。

今回は任意の描画パスを操作するベクターエディターやクラウドAI生成サービスの新設を含めない。任意のUIの完全再現を保証せず、固定の部品内部と基本の装飾・文字設定が再現の壁にならないことを受け入れ基準にする。

## 検証

旧データ、複製、Undo、回転した親、空の選択、不正なフォント、書き出した装飾/文字、部品保存と再挿入をテストする。実ブラウザーでは異なる外観の画面を構築し、編集・プレビュー・出力・再読込を確認する。フォントは読み込み完了後に書き出し、必要なフォントをHTMLへ埋め込む。
